# Reference submissions and demo takeaways

The current Agent Tank page did not expose another submitted build when checked, so the useful references are public repositories from earlier GenLayer builder work. These are references for presentation structure, not templates to copy.

## ProofPilot

- Repository: https://github.com/Manablaq/proofpilot
- Strong point: the README immediately connects the live app, contract, deployment transaction, acceptance record, screenshots, and explicit scope limits.
- Takeaway for this project: show one complete evidence-to-contract story rather than listing every planned feature.

## AgentLiability

- Repository: https://github.com/tanphung/agent-liability
- Strong point: separates the real product problem, the reason GenLayer is necessary, the deployed contract state, and end-to-end transaction proof.
- Takeaway for this project: the demo must clearly separate deterministic revenue metrics from GenLayer's final bounded judgment.

## AI DAO Moderator

- Repository: https://github.com/typakon4/ai-dao-moderator
- Strong point: keeps a narrow demo flow around one concrete decision.
- Takeaway for this project: keep the recording under 90 seconds and avoid turning the video into a technical lecture.

## Prism

- Repository: https://github.com/Fato07/prism
- Strong point: polished product presentation and a short visual story instead of an unedited browser walkthrough.
- Takeaway for this project: record separate low-, medium-, and high-risk takes, remove loading time, and end on the stored GenLayer judgment.

## Recommended demo standard

1. State the problem in one sentence.
2. Show the clean input screen.
3. Demonstrate three meaningfully different outcomes with jump cuts.
4. Explain exactly what GenLayer adds.
5. End on the deployed contract and stored judgment.

Do not show terminal setup, package installation, long loading periods, wallet balances, or repeated failed transactions in the main demo.
